# Weekly Run Prompt

Paste this to kick off the weekly job hunt:

---

Run my weekly job hunt:

1. Show me a quick summary of my current `job_search_profile.md` and ask if anything needs updating (roles, locations, industries, constraints, availability) before you proceed. Wait for my answer.
2. Run the weekly job hunt per `weekly_job_hunt_workflow.md`, using `job_search_profile.md` for targeting. This includes re-verifying existing leads' links are still live, not just adding new ones.
3. Update `job_leads.md` with anything new.
4. Give me a summary of new leads and anything that needs my attention (stale applications, dead links, leads to follow up on).
5. Pick the single best-fit new lead from this run and draft one outreach email for it (e.g. to a recruiter, hiring manager, or referral contact) — draft only, do not send it. Show me the draft so I can edit and send it myself.
